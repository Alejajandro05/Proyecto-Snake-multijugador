# Asset layout

This folder keeps menu assets at the root for compatibility and organizes new gameplay art by category.

## Map assets
- `map/backgrounds/`: board backdrops
- `map/borders/`: frame and border overlays
- `map/tiles/`: floor tiles for the grid
- `map/obstacles/`: obstacle sprites
- `map/decor/`: non-interactive decorations

## Snake assets
- `snakes/player1/`: player 1 head, body, turn and tail sprites
- `snakes/player2/`: player 2 head, body, turn and tail sprites
